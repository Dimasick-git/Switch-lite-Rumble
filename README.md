# Switch Lite Rumble

Виброотклик на Switch Lite через встроенные динамики. Игра отправляет обычную
команду вибрации контроллерам, модуль перехватывает её и создаёт акустический
отклик в корпусе консоли. Вибромоторы для этого не нужны.

**Проверочная сборка 0.21.0 — подача аудио и короткие импульсы.** Изменение ещё
требует прогона на консоли. В опубликованном pre-release сейчас сборка 0.20.0.
Отклик и раздельная
регулировка проверялись на нашей консоли. Список совместимых игр ещё не собран,
поведение на других версиях системы требует проверки.

## Два аудиопотока

Игра продолжает воспроизводить свой звук. Параллельно модуль держит отдельный
аудиопоток для виброотклика и подаёт сигнал только при получении команд игры.
Оба потока выходят через встроенные динамики.

При включённом режиме физическая громкость динамиков удерживается на максимуме,
а качелька **+ / −** регулирует громкость самой игры через RyazhTune. Поэтому
игру можно сделать тише, сохранив полную громкость потока виброотклика.
Сила импульса при этом по-прежнему зависит от команды игры.

Профиль подобран на Lite: **225 Гц, сила 1000, противофаза каналов**, сглаживание
фронтов 5 мс. Из команды HD Rumble берутся амплитуды; сигнал воспроизводится
на фиксированной частоте. Низкий тон может быть слышен, а ощущение зависит
от игры, положения консоли и того, как её держать.

## Что входит в бету

- Перехват одиночных и пакетных HID-команд вибрации игр и homebrew.
- Раздельное состояние контроллеров и остановка зависшего сигнала по таймеру.
- Виброотклик меню Ryzhand и общий переключатель «Виброотклик».
- Управление громкостью игры кнопками консоли через рабочий RyazhTune.
- Исправление системной полоски: в уведомление `ovln` передаётся уровень игры,
  а не удерживаемый физический максимум динамиков.
- Восстановление обычной регулировки при выходе из режима.
- Тестовое приложение `Ryz rumble test` и диагностический журнал.

## Установка полного комплекта

Скачать **sdout.zip** из [релизов](https://github.com/Dimasick-git/Switch-lite-Rumble/releases).
В нём уже есть модуль, Ryzhand, загрузчик, RyazhTune, тест и ресурсы.

1. Сохранить копию своих настроек `config/ryazhahand` и `config/RyazhTune`.
2. Распаковать содержимое ZIP в корень SD-карты с объединением папок.
   Настройки из архива рассчитаны на пробу: вибро включено, эффекты меню выключены.
   При сохранении своего конфига включить `haptic_feedback=true` в Ryzhand.
3. Полностью выключить и включить консоль. Перезапуска одного оверлея недостаточно.
4. Открыть игру, включить в ней вибрацию и проверить действие с отдачей.
   Кнопки **+ / −** должны менять звук игры и системную полоску громкости.

В `Ryz rumble test`: **A / X** — импульсы, **L / R** — стороны, **B** — остановка,
**ZL** — короткий импульс около 30 мс, **Y** — режим контроллера, **+** — выход.
Тест тоже отправляет HID-команды. Сборка 0.21.0 убирает SD-операции из
непрерывного воспроизведения и сохраняет короткие команды между аудиоблоками.

## Ограничения беты

- Только Switch Lite и встроенные динамики. В наушниках раздельный режим отключается.
- Игра должна отправлять команды вибрации. Некоторые игры на Lite их не отправляют.
- Пока активен режим, другие системные звуки используют полный физический уровень
  динамиков; отдельная регулировка применяется к текущей игре.
- Полная тишина и точное воспроизведение всех эффектов HD Rumble не гарантируются.
- Совместимость с другими перехватчиками `hid`, `audctl` и `ovln:rcv` требует проверки.

Если после установки консоль не загружается, на ПК отключить только
`atmosphere/contents/4200000000525652/flags/boot2.flag` и перезапустить её.

Для отчёта об ошибке нужны название игры, версия системы/Atmosphere, действие
для проверки и `config/ryz-lite-rumble/runtime.log`. Полезны также результат
теста A/X и строки `volume UI` / `hud` из журнала.

## Настройки

`config/ryz-lite-rumble/config.ini`, перечитывается примерно раз в секунду:

```ini
[rumble]
enabled=1
gain_percent=200
boost_weak_signals=1
watchdog_ms=1000
game_volume_buttons=1
```

`gain_percent`: 0–400. `watchdog_ms`: 0 отключает таймер, иначе 100–10000 мс.
`boost_weak_signals=1` поднимает слабые импульсы в синтезаторе кривой sqrt
после применения gain. Ноль возвращает линейный отклик предыдущей беты.
Выключение `haptic_feedback` в Ryzhand отключает синтез и раздельный режим.
`sound_effects=false` отключает обычные эффекты меню, сохраняя виброотклик.

## Исходники и сборка

Ветка `emulation`. Нужны devkitPro/devkitA64 и g++ с C++20 для хост-тестов.
Зависимости закреплены сабмодулями: Atmosphere-RYZ v8.1.0 и Ryzhand.
Для Atmosphere нужна свежая libnx; используемая CI ревизия указана
в `.github/workflows/build.yml`.

```sh
git clone -b emulation https://github.com/Dimasick-git/Switch-lite-Rumble.git
cd Switch-lite-Rumble
git submodule update --init Atmosphere-RYZ
make
make test
make dist
```

`make dist` создаёт SD-структуру модуля и теста в `sd/`. Для сборки вместе
с Ryzhand нужен доступ к его зависимости `libryazhahand-deko`:

```sh
git submodule update --init --recursive Ryzhand
make full
```

С готовой libstratosphere: `make AMS_ROOT=/путь/к/Atmosphere AMS_CHECKED=1`.
Полный ZIP с рабочими компонентами можно собрать скриптом
`python3 scripts/package_release.py --base /путь/к/полному-комплекту`.
Скрипт заменяет модуль и тест свежими сборками из этого репозитория.

Хост-тесты проверяют маршрутизацию, синтез, кнопки, шкалу, восстановление
громкости, INI и формат уведомлений. Проверки сборки не заменяют прогон на консоли.
Разбор канала системной полоски описан в
[docs/native-volume-notification.md](docs/native-volume-notification.md).
