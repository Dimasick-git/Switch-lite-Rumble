# Switch Lite Rumble — проверочная сборка 0.20.0

В присланном журнале BOTW подключается к HID-перехвату, а показанные счётчики
seen/accepted совпадают. Есть ненулевые команды: пик входа около 113/1000,
синтезированный PCM — около 7373 из 32767. Тестовый апплет достигает 32767.
Перехват работает; слабая амплитуда может объяснять отсутствие ощутимого
отклика. Журнал сам по себе не подтверждает, что импульс дошёл до динамиков.

## Изменение

В синтезаторе тихие импульсы усиливаются кривой квадратного корня после
обычного gain. На воспроизведённом примере из журнала PCM-пик поднимается
с 7373 до примерно 15543. Порядок силы эффектов, точный ноль и цифровой
максимум сохраняются. Частота остаётся 225 Гц, каналы — в противофазе,
сглаживание — 5 мс. Сами команды для физических контроллеров не меняются.
Громкость игры по-прежнему регулируется отдельно. Низкий тон отклика может
стать заметнее: усиливается именно этот сигнал.

Новый ключ config/ryz-lite-rumble/config.ini:

    boost_weak_signals=1

Он включён и при отсутствии ключа в старом конфиге. Значение 0 возвращает
линейный отклик 0.19.0. Настройки слайдеров и новые пункты меню не добавлены.

## Диагностика

Строка seen/accepted теперь содержит audio (открыт ли поток), err (последняя
ошибка аудио), boost (включено ли усиление), hh/pad (ненулевые команды от
встроенного управления и внешних устройств) и nz_handle (последний ненулевой
handle). Счётчики и пики накопительные, сбрасываются при смене программы;
это не мгновенный измеритель текущей силы. Поле game относится к последней
замеченной команде, счётчики сигнала — к последней принятой программе.

## Проверка

Это локальная сборка для проверки, результат на консоли пока не подтверждён.
Сохраните конфиги, распакуйте комплект в корень карты и полностью перезапустите
консоль. Включите виброотклик в Ryzhand и проверьте в BOTW ту же сцену, где
внешний геймпад даёт отдачу. Затем сохраните runtime.log.

Есть тест, который воспроизводит амплитуду BOTW из журнала. Также проверены
ограничение максимума, тишина, Stop, watchdog, монотонность, противофаза и
маршрутизация Pro/Handheld. Ощущаемый результат и совместимость требуют
физической проверки. Для возврата можно установить опубликованную 0.19.0.
